# 教师工作区与分步任务重构

2026-10-17，依据用户明确要求重新组织教师界面。教师使用大模型一键批阅仍是核心；独立互批保持独立。设计参考[Gradescope 的纸面作业流程](https://guides.gradescope.com/hc/en-us/articles/22011014475405-What-are-my-options-for-having-students-submit-work-to-Gradescope)和[MagicSchool 的写作反馈工具](https://www.magicschool.ai/tools/writing-feedback)，采用任务驱动、先明确要求和标准、再收取与反馈的操作组织，不复制其界面或评分结果。

| 入口 | 负责内容 |
|---|---|
| 工作台 | 真实最近任务、当前批次待批/完成数及授权班级数，不生成虚构全校待办统计 |
| 写作任务 | 写作要求→评分标准→选择班级；预览并确认名单后建立任务 |
| 任务内步骤 | 任务概览、写作单、收取、AI批阅、核对发布；互评材料为可选交接 |
| 快捷批阅 | 沿用原题目/标准、上传和一键批阅；复杂标准进入独立编辑页 |
| 批改档案 | 当前报告、云端存档、原版档案；保留编辑、版本、保存、PDF/打印、CSV |
| 学情分析 | 原班级分析、学生档案及历史分析处理 |
| 班级与学生 | 授权学校名单与拼音检索；私人名单另有管理入口 |
| 模型与设置 | 批改/OCR、导出设置、备份恢复分栏；密钥处理沿用原服务端实现 |

采用浅色、细边框和统一青绿色操作色。桌面侧栏，手机菜单和底部四入口；手机关闭的菜单不可聚焦，任务条自动显示当前步骤。内嵌步骤不再叠加整屏弹窗和重复标题；报告预览仅属于档案页，缩略图默认收起。未保存草稿/报告/互评转写跨页先确认；处理中阻止切换。侧栏和“下一步”使用相同阶段规则；草稿未确认名单不能提前收取，缺批阅权限不能从页尾进入批阅，已结束任务不能签发新写作单或新增互评材料。

## 本机验证

合成Daily账号通过正常交接进入实际本机Worker，无真实学生数据和模型费用。界面走通：三步创建→保存草稿→预览130人（含独立同名账号）→确认建立→内嵌写作单→收取页拼音首字母hctm筛出两个独立同名学生并选择。班级搜索隐藏已选项后保存仍包含其班级。评分分项19/20时下一步禁用，恢复20/20可继续。未保存草稿切换工作台触发页面内确认，取消后题目保留。

已有合成报告在独立核对发布步骤打开，完整六大栏目、原稿/标准、版本、教师编辑和发布控制保留。编辑后跨页触发保护，取消后可保存为第4版；保存不会自动发布。报告可载入原导出与分析工作区。模型/OCR、导出和数据设置分栏，切换后不混入旧打印缩略图。375/390/768/1440宽度首页没有整页横向溢出，手机与桌面关键页截图已查看。

主项目212项、独立互批9项测试通过，构建和Worker预检查通过。新增4项覆盖草稿/任教权限/关闭状态/独立互批配置的步骤准入。源文件不修改Worker、数据库迁移、登录协议和批阅评分算法。

浏览器工具上传本机合成图片受Chrome扩展文件访问设置限制，本轮没有声称完成新版上传后的真实拍照/OCR/模型质量验证；已有后端和原上传路径回归继续通过。新建任务、名册、报告编辑均为合成环境；真实教师两班权限另见[账号核验](pilot-account.md)。实际设备相机、软键盘、打印、中文手写OCR及真实模型结果仍待试点。
