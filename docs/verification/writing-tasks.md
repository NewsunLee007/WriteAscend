## 手机浏览器流程

执行 `scripts/qa/writing-tasks.cjs`，390×844 独立浏览器上下文通过：

1. Daily 登录、显式带入旧设置、选择授权学校班级，使用原题目与 rubric 创建任务草稿。
2. 修改原题目后更新草稿，标准版本变为 2；接口读取版本 1，原题目保持不变。
3. 完整读取 130 人学校名单；搜索同名学生仍显示两条，各自短编号不同。
4. 确认建立任务，服务端保存 130 个成员；已建立任务更新标准返回 409。
5. 载入原批改界面，恢复题目、班级和 130 人名单，不推测学号。
6. 上传合成同名作文，沿用原一键模型批改，模拟模型只调用一次。报告保持原格式、15.5 分及 sourceTask 来源版本。
7. 两个同名身份不会被自动选中，结果为 ambiguous、student_id 为空并保留两个候选。
8. 编辑姓名为唯一学生，当前报告进入对应本机档案；改回同名后，当前记录从旧学生档案解除，报告不丢失。
9. 当前已有作文时载入任务受到保护，不把旧报告套用新标准。任务名单可搜索、任务可关闭，手机页面没有横向溢出。
10. 退出并切换另一教师，无授权班级提示可见，访问前一教师任务返回 404。
