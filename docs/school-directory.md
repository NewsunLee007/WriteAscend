# 学校目录、学期与教师授权

本阶段给原教师作文系统补充学校身份关联。原私人班级、作文上传、大模型一键批改、教师核对、报告内容和导出继续使用；教师不需要先建立学校目录才能使用私人批改。学生互批仍为独立项目。

## 已确认的目录参数

用户于 2026 年 10 月 16 日确认：学校名称为 **瑞安市新纪元实验学校**，学期键为 `2026-1` / `2026-2`，分别代表 2026 学年第一、第二学期。默认值放在 Daily 集成的 `writing-school-config.mjs`，管理员可在预检前修改；不从电脑日期推算。

现有字段 `academicYear` / `academic_year` 保留名称，但新建目录严格使用 `YYYY-1` / `YYYY-2`。学校、学期、源班级共同确定稳定班级身份；新学期创建独立班级，旧作品与成员关系保留，任教权限需要重新设置。

## 管理员操作

真实管理员登录后可打开“学校目录与教师授权”。普通教师不显示入口，也不会加载该界面的 JavaScript。

1. 选择已有学校或填写新学校，明确学期，勾选源班级。
2. 预检列出各班人数、新增、移出、改名、同名及原班关系结束数量。选择、学期或学校变化后须重新预检。
3. 核对具体变更后勾选确认，再同步目录。来源或目录在此期间变化会拒绝确认，要求重新预检。
4. 选择已启用的学校教师账号及班级，分别授予读取名单、管理任务、批改、发布权限。发布权限默认不勾选；报告发布与学生本人查看流程已实现，真实学校试点仍待验收。
5. 可撤销教师权限，或核对后停用整个班级。停班结束当前成员关系并撤销该班授权；重新预检可恢复班级与学生稳定 ID，但不会恢复旧教师权限。

同步仅作用于勾选班级；同一学校、学期内已转入所选班级的学生，其原班关系会结束。源班级已被另一学校在同一学期占用时拒绝重复归属，不按相同学校名称自动合并目录。

## 数据与权限边界

Daily 保留正式目录，WordUp 继续作为账号与在用学生来源。只读来源查询学生的 ID、姓名、年级、班名和状态，以及教师 ID、姓名和状态；不读取口令、PIN 或会话签名信息。教师权限使用学校教师账号稳定 ID，不按名字匹配，也不能把学生 ID 当作教师授权。

`writing_memberships` 保留当前投影；`writing_membership_periods` 分段保存加入、离开、返回和观察到的姓名变化。已有旧成员首次被观察前的姓名不能推测，历史观察时间单独记录。`writing_directory_operations` 对同一操作去重，`writing_directory_audit` 保存操作人、结果及此前目录业务状态。同步和授权在数据库事务中执行，并检查目录摘要或记录版本，避免重复提交及覆盖其他管理员的修改。

Worker 的 `/api/admin/writing-directory/*` 只转发允许字段，角色与操作人来自当前来源核验后的会话。写入还要求同源与当前工作区标识。Daily 再次核验机器凭据、授权及管理员角色。普通教师的班级读取和任务成员访问继续逐次核验当前权限，撤权不必等旧 Cookie 到期。

目前目录是管理员主动预检同步；不是自动监听 WordUp 的名册变化。教师读名单仍会核验当前源身份、年级、源班级及成员关系。操作审计不是一键数据回滚工具，正式启用需要另有数据库备份与恢复核对。
