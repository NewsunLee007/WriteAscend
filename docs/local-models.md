# 本地模型接入

入口：教师工作区 → 模型与设置 → 批改与识别模型 → 使用本地模型。

1. 在模型电脑安装并启动 Ollama、LM Studio 或 OpenAI 兼容的 vLLM 服务，准备能读取图片并输出文字的视觉语言模型。
2. 点击“连接本地模型”，选择运行程序。默认地址分别为 `http://127.0.0.1:11434/v1`、`http://127.0.0.1:1234/v1`、`http://127.0.0.1:8000/v1`。已有内网服务可以填写其地址。本地服务密钥可留空；启用服务鉴权时填写实际密钥。
3. 生成并下载连接文件，在模型电脑安装 Node.js 20 或更新版本，在文件所在目录运行页面给出的 `node NewsunEnglish-local-xxxxxxxx.mjs`。保持电脑、模型服务及连接程序运行。下载文件含专属连接凭据，应私下保管；丢失文件或更换本地地址时，移除旧连接并重新生成。
4. 回到设置选择本地视觉型号。“保存并使用”同时选择该型号用于批阅和 OCR，避免误用其他收费模型。也可另选已配置的云端专业 OCR。先执行“检查连接和图片识别”，再用少量真实手写作文核对识别与评分质量。

连接成功后可在手机上发起任务；模型电脑主动领取任务，无需开放入站端口、建立公网隧道或允许浏览器跨域。退出账号会撤销相关后台批阅授权。连接断开不会自动切换到云端或再次执行已发出的请求。

## 数据与任务处理

- 这是本地**推理**模式。题目、作文照片、结果和教师发布流程仍使用现有学校云端工作区，不能将其描述为“数据完全不出本机”。模型服务如果自行转发到其他后端，其数据去向由教师选择的服务决定。
- 电脑服务地址和本地服务密钥仅存在下载文件，不写入云端配置。网站专属连接凭据按现有个人模型机制加密托管，连接只领取该教师该配置下已授权任务，不能读取其他配置或学生目录。
- Ollama 优先查询 `/api/show` 的 `vision` 能力；LM Studio 优先使用原生目录的 `capabilities.vision`。兼容目录缺少能力时采用保守视觉型号名称规则。文本、向量、音频型号不进入自动推荐。自定义视觉型号需教师明确确认，并通过实际图片检查。
- 结果通过已有授权、租约、配置版本、班级权限、任务状态及撤销检查后，进入原有批阅流水线。格式校验、评分标准快照、报告编辑、导出、教师发布、学生查看均沿用现有逻辑。
- 一个连接逐份推理。请求处理中掉线或超时标记为“结果未确认”，需核对后显式继续。连接程序不重放模型请求；已获得结果先以原子文件写入 `~/.writeascend/local-results/`（目录0700，文件0600），重启后先回传待保存结果。授权或配置改变而被拒绝的结果在该目录留存，供人工核对。
- 本地运行参数默认最多10000输出token、300秒超时，与现有JSON报告流程一致。电脑性能、模型上下文、图片能力及手写识别质量需要实际核对。
- 移除连接立即阻止其领取和回传结果；已保存报告保留。连接不需要 Daily 重启，也不更改班级授权。

## 实现和验证

`0018_local_model_relays.sql` 仅增加连接在线状态及模型目录元数据表；不修改现有学生或报告表。Worker 的云端接口仍拒绝回环、内网和非HTTPS服务地址，本地模型由出站连接程序访问，未放宽云端SSRF边界。

新增集成测试覆盖本地批阅→教师发布→学生查看、设备凭据隔离、模型能力筛选、不确定响应恢复、移除/修改配置/退出/班级撤销/暂停后拒收结果，以及本地服务密钥不随请求传往网站。浏览器隔离验收使用合成账号、合成视觉服务和合成作文；不代表真实硬件模型或手写识别质量已经通过验收。
