## 版本与数据恢复

教师应用从当前版本回退到记录的 bootstrap UUID，健康端点确实返回旧版本；随后恢复至双向绑定版本。互批也独立回退并恢复；最终两个健康端点均返回表中当前 UUID，构建资源、页面策略和匿名拒绝仍通过。没有用再次部署新 UUID 冒充恢复到原版本。

在实际应用测试库加入不关联任何学校身份的技术探针：教师库为不可匹配真实授权的撤销记录，互批库为已消费且过期的登录事务。版本切换后分别核对记录保持一致；已按精确标识清理并核对影响行数。私有 R2 合成探针在切换后字节摘要一致，随后删除。没有创建可登录的合成学校账号。

另外新建 `writeascend-staging-restore-drill`（`9610cb02-c37a-4178-8a3f-c848a7aece56`），建立单行技术表并导出，记录书签后把值从 `before/1` 改为 `after/2`，实际执行 Time Travel，读回精确的 `before/1`。该库没有绑定教学应用，保留供重复演练。没有对教师、互批或正式业务库执行数据回退。

代码版本回退与数据恢复分别验证，不能将其中之一称为完整替代。D1/R2 实际教学数据的恢复、旧浏览器数据迁移及正式切换仍需在试点中继续核对。
