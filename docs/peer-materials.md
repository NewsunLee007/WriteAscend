# 教师确认的互评材料交换

2026-10-17。本阶段已实现 WriteAscend 材料准备与独立互批项目的教师导入页。尚未向学生开放互评任务；轮次、标准提示确认、训练、分配和反馈页面继续开发。

## 教师操作

在“写作任务”中选择已建立任务，打开“准备同伴互评”。这项入口仅在管理员配置独立互批连接后出现，不改变默认一键批阅。

选择一个班级与稿次，按中文、拼音或首字母查找学生；同名按学校账号短编号区分。只可选择已收齐的当前原稿。教师对照原稿照片录入转写，也可从对应当前输入的已有报告载入 `original_essay`。不会载入升级稿或范文，不要求先进行 AI 批阅。每份核对后可直接进入下一份；输入变化会取消该份确认。

教师核对供同学阅读的标题、写作要求、原文和原教师标准，确认去除身份信息后保存。脱敏由教师核对，系统不宣称自动识别或删除所有个人信息。任务原标准及已存原稿保持原位，分享形成新的不可变快照。每份分享至多 300 人，请求及合并标准后的快照均至多 1 MiB，较大材料可分组。

保存后进入独立互批项目，以同一任课教师学校账号登录，预览材料和教师标准，再确认保存。独立库保存成功后向来源确认回执；丢失回执重试沿用同一导入记录和回执，不重复建材料。教师可在原任务撤回分享。

## 配置

| 服务 | 变量 | 用途 |
| --- | --- | --- |
| WriteAscend | `PEER_ORIGIN` | 固定互批来源，不接受请求指定任意目标 |
| WriteAscend | `PEER_EXCHANGE_TOKEN` | 独立机器凭据，至少 32 字符，不等于教师 Daily 凭据 |
| 互批 Worker | `SOURCE_ORIGIN` | 固定 WriteAscend 来源 |
| 互批 Worker | `SOURCE_EXCHANGE_TOKEN` | 与来源交换凭据一致，不等于互批 Daily 凭据 |

公网必须 HTTPS，本机回环开发允许 HTTP。凭据仅保存在服务端，不返回浏览器；缺配置时分享入口关闭。没有加入远程互批绑定或修改正式环境配置。

## 协议与存储

- 教师接口：`GET /api/peer-sharing/config`；`GET/POST /api/tasks/:taskId/peer-exports`；`POST /api/tasks/:taskId/peer-exports/:exportId/revoke`。
- 来源机器接口：`POST /api/integrations/writing-peer/export`、`receipt`，仅接受独立交换凭据。固定互批服务提交其刚通过 Daily 核验的教师身份与当前 `peer.manage` 班级版本；来源核对原任课教师、目标、班级及授权版本。
- 独立互批教师接口：`GET /api/imports/:exportId`、`POST /api/imports/:exportId/accept`；写入要求同源、当前工作区及仍有效的本地会话。退出发生在来源核验期间也不能返回材料或新建导入。
- `newsun-peer-source-v1` 保存来源任务/标准、稿件输入摘要、教师核对的文本和最小服务端身份关联；内容摘要为 SHA-256，JSON 对象键递归排序、数组保留顺序。该规则与互批领域核心自己的版本摘要算法区分。
- 独立项目不导入教师实现。机器通道中的账号/成员/稿次关联只存服务端；教师导入页的响应只给材料代号、文本和教师标准，不返回整份身份对应表、照片、模型凭据或批阅报告。
- 来源迁移 `0014_peer_exports.sql` 保存分享及回执；互批迁移 `0002_source_imports.sql` 保存独立导入与待确认回执。两项均只应用本机 QA 数据库。

来源读取前检查分享、任务状态/修订、学生任务关系、当前原稿输入和标准版本；撤回、关闭/重新开放、停用成员或更换原稿都会停止旧分享。每次教师导入页读取和写入仍向来源核验，暂不可达时不退回缓存正文。浏览器已收到的内容无法召回，不作相反承诺。

## 下一阶段的必要边界

以上机器授权只用于原任课教师导入，不能直接用作学生读取权限。开放实际互评前，仍需实现学生当前分配、学校有效成员、分享教师持续授权、来源有效性和反馈发布核验；不能靠伪装教师或复用过期教师交互登录来读取。轮次代号必须另行生成，不能将导入顺序代号直接当作匿名学生编号。

领域核心已有学生标准映射、平衡分配、证据反馈和作者回应，但本阶段尚未将其接成课堂活动。还需连接同伴反馈版本与自主二稿，保留原教师反馈路径。验证见 [材料交换记录](verification/peer-materials.md)。
