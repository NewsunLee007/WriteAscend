# 旧版数据与工作区备份

教师“设置 → 数据管理”保留原备份/还原入口。新版完整 JSON 备份新增四类历史：CSV导出、已保存批次、评分标准备份、班级分析；同时保留原设置、当前作文与原批语/分数、学生档案、打印及CSV选项。格式为 `writeascend-workspace-backup-v1`，仍保留原顶层字段，原已导出的无schema备份也可读取。

当前文件读取上限32MB，实际可恢复规模还受浏览器本机存储容量影响；超限或存储不足会明确拒绝并保留输入文件，不以截断历史记录的方式完成恢复。

选择文件时只在本机解析、排除已知认证字段并显示作文/班级/档案/历史数量，尚不修改工作区、不上传文件。可先下载当前工作区备份，再确认恢复。云端模式确认前重新核对当前教师工作区；账号变化、退出、正在批改/分析或读取失败时不应用。恢复只替换文件包含的数据；旧文件没有的四类历史不会被清空，重复恢复同一完整文件也不会追加重复历史。

设置、档案与四类历史在改变React状态前先写入本机存储；存储失败则释放本轮写入并恢复先前值，预览保留以便重试。临时作文仍由现有IndexedDB草稿机制保存，照片/临时稿写入失败继续显示原有提示；不把localStorage回退称作跨所有浏览器存储的原子事务。备份文件本身应保留，不能用“恢复成功”代替长期备份。

原姓名、本机学号与班级编号作为历史业务信息保留，不能成为学校账号授权依据。恢复后的当前批次解除之前的云端存档和写作任务关联，避免把旧作文覆盖或发布到当前学校作业；必须重新核对真实学生归属。已嵌入备份的PNG/JPEG/WebP/GIF原图可以保留；过期blob链接、外部地址与SVG图片不会在恢复时加载，未包含的原图需重新选择。

API Key、认证Header等字段在备份输出、备份预览及旧本机数据拷贝前经过现有 `sanitizeLegacy`。个人云端模型配置和服务器密钥仍使用原配置流程，不随文件迁移。旧文件从磁盘读取，识别为备份后在浏览器中处理，不会先将含密钥的原JSON发到后台。

## 原域名与测试域名

浏览器存储按来源隔离。正式域名后续从GitHub切到Cloudflare时，如果协议/域名/端口不变，新版能发现同一浏览器中的原键名，登录后由教师明确选择带入。拷贝前先解析所有键，格式错误不产生部分写入；空间不足时恢复先前状态，刷新后仍可重试，原键和值不删除。

独立 `workers.dev` 测试域名不能读取原域名的本机数据，需使用文件备份。原始旧版“备份数据”不含四类独立历史，文件里没有的内容不能凭空恢复；完整原域名迁移仍须在原设备中验收。切换前还应保存原页面当前批次并保留照片，不能假定未保存的内存文件会自动跨来源迁移。

本轮合成数据验证见 [验证记录](verification/workspace-migration.md)。真实教师浏览器数据、正式域名与跨设备完整同步并未由这组检查证明。
