# 教师发布与学生自助查看验证

2026-10-17。本阶段以本地 Worker/D1/R2、合成 Daily 来源和模拟模型响应验证，未写正式学生数据、未启用正式桥接、未切换域名、未部署远程环境。此记录补充上一阶段的 [稿次关联批阅](bound-grading.md)，不把本地通过等同于正式上线。

## 已实现

1. `0008_report_publications.sql` 增加每稿的发布头、不可变发布版本、操作回执、按发布版本记录的学生查看记录和 Daily 集成事件 outbox。本地 QA 数据库已应用；正式/远程启用前必须先应用 0007/0008。
2. 教师发布前须确认原稿、学生归属、评分与反馈；当前报告修订、输入摘要和发布头版本全部匹配。姓名识别差异须先核对并保存。发布前与快照保存后分别核对当前发布权限；失效不发布。
3. 学生看到的是经确认的独立发布快照。教师后续编辑保留新报告修订，已经发布的内容不随编辑改变；再次发布才更新学生版本。撤回停止报告、图片和阅读确认接口的访问，旧版本留作教师内部审计。
4. 收取原稿的替换/删除与旧反馈撤回在同一 D1 事务中处理，原稿更正后不能继续向原账号展示旧反馈；旧报告必须重新批阅、核对后才能发布。
5. 学生使用原 Daily/WordUp 学校身份进入“我的作文”。前端依据验证后的角色载入独立学生页面，不加载教师模型配置或迁移教师本机数据。匿名及过期流程支持学生登录返回路径。
6. 学生列表仅查询固定接收者为本人且当前仍可读的发布记录。登录来源仍逐请求核验；使用稳定 WordUp subject，不靠姓名或本地序号。历史班级成员关系结束并不把反馈改绑他人；合法学校账号可查看自己的历史发布记录，任务成员被停用或发布撤回则停止访问。
7. 学生视图只含六部分反馈、自己的原稿、题目、教师评价标准及发布元数据；不下发原模型响应、纸面识别的其他身份、后台提示、模型配置、原稿摘要或全局账号映射。图片采用学生专属的已发布反馈接口，不能调用通用教师图片接口。
8. 学生查看后记录对应发布版本的查看时间；它只表示打开查看，不代表理解或修订质量。学生页面提供刷新、只读报告、原稿/识别稿、打印入口；支持作文列表及稳定报告链接。
9. 教师报告页显示发布状态、当前学生可见版本、查看状态；保存修改与发布分开。班级列表批量读取运行/发布状态，避免每名学生单独发起一次 D1 查询。

- 原本地完整/快捷批阅、暂停与失败重试、教师编辑、CSV/JSON、云端运行、存档、先选学生拍照及界面回归通过。没有因新增学生角色改变默认教师一键批阅路径。
- 实际 Daily 项目当前 203 项测试通过。学生交接页源码已通过安装摘要预检并更新，快照为 `audit/private/daily-bridge-2026-10-16T16-13-54-392Z`；未改 `.env`、未重启正式 Daily 服务。该安装只更新集成包清单文件，不复制账号库或媒体。
