# 独立互批核心与研究核对验证

2026-10-17。独立项目 `apps/peer-review` 已建立，当前是领域规则与接口规格阶段，不是可登录的学生互评应用。未修改实际 Daily 的运行配置、正式学校目录、既有教师流程、远程 Worker 或 DNS。

## 已执行

- 独立 `package.json`、包锁与 TypeScript 配置；`npm ci --prefix apps/peer-review --ignore-scripts` 成功，再运行独立测试和类型检查通过。代码不导入教师页面或评分核心，没有把互批配置加入原教师默认流程。
- 原系统 135 项测试通过，记录在 [原系统回归](peer-core-teacher-regression.txt)。独立项目最终 8 项规则测试通过，见 [互批核心测试](peer-core-tests.tap)；末项补充异步校验期间的输入快照保护。两个集合均使用合成数据，不构成真实账号或课堂试点证据。
- [源文件摘要与检查清单](peer-core-evidence.json) 固定当前核心、包锁和测试版本。`npm run peer:check` 通过。
- 保留教师原分项名称/分值/合计、字数严格设置、时态和标准版本；未确认/漏映射/自定义说明缺失/合计不同均拒绝。文字材料的书写卷面不能进入学生档位，学生投影去除确认教师的内部账号。
- 130 人、每人两份，确切产生 260 项分配，每人给出与收到的份数一致，无自评、重复稿件或被排除关系。相同本轮种子和成员快照可重现，成员输入顺序不影响结果；严格排除可行时完整匹配，不可行时整体失败，不返回部分名单。
- 反馈绑定精确材料/标准摘要；伪造原文引用、额外总分字段、陈旧版本、没有具体建议的负面档位、未提问的不确定判断均拒绝。作者回应须覆盖建议/问题，采纳需说明怎样修改；可以给出有理由的保留意见。
- 校验开始后更改调用方的材料、标准、反馈或回应对象，不会改写正在校验的版本；存储反馈被改动而摘要不符时，作者回应被拒绝。版本摘要不是认证机制，后续服务端仍须从自身存储读取冻结版本并验证用户权限。

## 原始依据

[来源清单](peer-research-sources.json) 记录官方 PDF 的字节数、SHA 和实际核对页。Cambridge A2/B1 的评价表已渲染并目视检查；教育部扫描原件已核对封面、目录及选定初中目标/评价章节。CEFR 书面产出正文通过网页读取，附录表格目视复核未完成，未据此移植分档。

[研究说明](../peer-review-research.md) 区分官方框架、研究结果与本项目的中文课堂改编。不宣称改编已在本校获得信效度验证，不保证固定提分，也不把研究中的设计分类解释成最优方案排名。课堂样稿训练和本校试点尚未执行。
