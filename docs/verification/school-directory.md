## 手机浏览器与现有功能

`scripts/qa/school-directory.cjs` 在实际本地 Wrangler/workerd、D1 和合成 Daily 服务中，以两个独立 390×844 浏览器上下文完成：

1. 管理员预检 2 班、133 人，确认同步，保存教师四项权限；重复选择已有授权后更改复选框不会被后台状态刷新覆盖。
2. 另一教师登录，读取获授权班级，使用原题目与 rubric 建立任务并确认 130 名成员。
3. 管理员撤权，教师原会话下一次请求立即失去班级与任务成员访问权。
4. 重新授权、停用班级、预检恢复成员，验证 130 人和班级 ID 保留，旧权限仍为撤销状态。
5. 普通教师没有管理入口，不下载管理员界面代码，直接请求管理接口返回 403；手机无横向溢出，无页面异常。

脚本返回 `passed: true`；`output/school-directory-grants-mobile.png` 已目视核对。调试中发现切换授权后的状态刷新可能覆盖复选框选择，已改为在选择教师/班级时同步读取权限并重跑通过。

原 `teacher-workflow.cjs`、`quick-grading.cjs` 和 `cloud-grading.cjs` 本轮回归通过，继续使用完整原报告和原模型处理链路。批量暂停、继续及失败重试沿用上一阶段已通过的验证，本轮未改动其处理逻辑。
