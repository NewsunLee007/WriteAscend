## 实现与边界

教师核对发布和 outbox 原子保存，独立 `FEEDBACK_EVENTS` 队列负责摘要投递；模型队列不承担同步网络请求。Daily 以机器凭据验证可信签发方，只保存已审批摘要和根据回调白名单生成的完整报告入口；交互登录过期不取消已确认事件的交付。原稿、全文、模型配置和原始响应不进入 Daily。

每稿学生/教师/任务绑定固定，事件 ID 与内容摘要去重，发布版本单调，撤回保留墓碑。错序或重复消息不重新调用 AI，也不能复活旧反馈。连接失败退避重试、配置失败显示管理员提示；教师可手动核对回执或补发。每日重新投递当前已确认事件以修复 Daily 备份恢复后缺失的记录。

Daily 版本领先源库或同版内容冲突时，源端暂停该稿学生报告与原稿访问，并阻止继续发布；恢复正确完整源记录并核对后解除暂停。不能通过重置计数掩盖版本冲突。Daily 摘要异步更新，网络中断时撤回摘要可能滞后，但源端完整报告与原稿即时拒绝访问。
