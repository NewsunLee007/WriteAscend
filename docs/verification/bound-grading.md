2026-10-16。本轮全部使用合成学校、教师、学生、照片与模型响应。未切换正式域名，未使用真实模型密钥，未写入正式名册。本地提交不等于已推送或部署。

## 实际实现

- Migration 0007 增加运行、模型步骤、模型任务绑定、幂等操作、报告及不可变报告修订。已应用于忽略目录下的本地 QA D1；正式或远程环境启用这些接口前必须先应用迁移。
- `/api/tasks/:id/grading` 只接受已收齐且由教师确认的稿次，后台从已存题目、rubric 与原稿构造模型请求。浏览器不能替换评分 system prompt。原评分与提示块仍与 GitHub 基线一致。
- 每次运行固定学生 provider/subject、class、task/rubric/input 版本和摘要、模型配置版本、模型副本页顺序及摘要。纸面姓名不同会提示核对，不据此改绑同名账号。更换原稿不覆盖旧输入、旧运行或旧报告。
- 原完整批改、一次 JSON 修复、优化稿修复和有界难度修复在后台推进。后续润色不能替换第一次识别的原文、原句或已形成的评分。模型响应保存在私有 R2，恢复已完成响应不重新调用模型。
- 同一输入/模型默认复用已有运行；明确重新批阅须引用当前最近完成的运行、说明原因，并设置 `confirmBillable: true`；可主动选择另一已配置批改模型。排队超容量时等待后续调度。失败、暂停、请求状态不明分别处理；状态不明不自动建立第二次请求。已有正文结果而后续步骤失败，可由教师说明原因后保留结果并记录未完成调整的提示。
- 模型任务和报告读取均检查教师归属及当前班级权限，付费调用前重新检查 Daily 授权。学校权限撤销时，尚未发送的请求会停止。所有新写接口受同源和工作区检查保护。
- 教师修改通过预期版本和操作回执保存新修订，不能改绑学生、原稿或已固定依据；分项、总分、半分精度及基本内容类型须有效。AI 原始第 1 版保留。
- 班级批阅页面支持拼音首字母检索、同名区分、稿次/模型选择、批次状态、异常处理、查看原稿、保存修改、下一份以及回到导出/分析。加载关联报告时导入完整任务名册，不将已确认身份再次送入姓名模糊匹配。
- 多页照片总量过大时，准备保留整页的图片副本，原图及其摘要仍保留。副本的真实拍摄质量和浏览器兼容性还需要实测。
