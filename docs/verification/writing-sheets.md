## PDF 与二维码

浏览器实际打印输出 `output/pdf/writing-sheets-synthetic.pdf`。`pdfinfo` 核对为 A4、5 页、无内嵌 JavaScript。Poppler 渲染后目视核对任务说明、初页和续页：姓名班级、页码、二维码、22 行书写区及页尾均无裁切或重叠。这是早期22行版本的历史证据，当前版式见下方18行更新记录。

`scripts/verify-writing-sheet-pdf.mjs` 以 120 DPI 渲染全部页面，用 jsQR 从实际页面图像读回二维码：4 页均可识别、4 个不同页面码；各页旋转 180° 后仍识别为同一码。公共证据不输出二维码原文，见 [PDF 验证 JSON](writing-sheet-pdf.json)。解码 API 依据 [jsQR 官方说明](https://github.com/cozmo/jsQR)；本轮该库仅用于开发验证，不增加教师首屏扫码代码。

另外 `scripts/qa/writing-sheet-long-print.cjs` 验证 45 段长要求的说明页延续及书写页页尾布局，实际 PDF 为 4 页说明加 1 页写作单；PDF 文本提取核对 1–45 条要求完整且顺序一致，各说明页有上边距，书写页尾保留。见 [长题目验证 JSON](writing-sheet-long-pdf.json)。

## 尚未验收

PDF 图像解码不能替代真实打印、复印、光照、折痕、手机相机和手写 OCR 测试。当前完成的是写作单及受权限保护的扫码核对接口；相册批量与连续拍摄收作业、页面持久化与替换历史、正式稿次和批改输入绑定、学生发布与 Daily 回传仍需开发。写作单生成不代表学生已交作业，也不代表已完成全系统升级。

后续手机拍照、相册收取、弱网待传及稿次输入已完成本地合成数据验证，见 [收作业验证](writing-collection.md)；真实纸面和手机硬件仍需实测。

## 18行宽行距更新（2026-10-17）

按用户要求改为18行。新模板为 `handwriting-a4-v2-18-lines`，常规正文区171毫米，行距约9.5毫米。较长页眉需要更多空间时，正文区可收缩至最低144毫米（行距8毫米）。底部自由书写区至少14毫米，不另加学生必须完成的项目。姓名、班级、二维码、四角定位点、页码和交稿自查保留。
