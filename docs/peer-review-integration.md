# 独立互批项目与现有系统的接入方案

2026-10-17。已建立 `apps/peer-review` 独立项目和经过测试的领域核心；本文件是接下来要实现的接口/权限规格，尚不是已完成的登录、API 或发布能力。

## 三个系统的职责

| 系统 | 权威数据与操作 | 不转交的内容 |
| --- | --- | --- |
| Daily / WordUp | 验证原账号，学校/学期班级、成员及老师权限 | 原 Cookie、认证密钥、密码/PIN |
| WriteAscend | 当篇任务/rubric、真实原稿与稿次、教师 AI 批阅与发布、自主二稿 | 模型凭据、整份原始报告、带身份的原图、内部 R2 路径 |
| 独立互批应用 | 互评轮次、标准映射、训练、分配、学生反馈、教师处理、作者回应 | 只向分配的同学开放指定脱敏文字，不下发整班姓名或身份映射 |

老师原有一键批阅、报告修改、导出和分析独立可用。互批是老师按任务主动使用的可选教学活动，不构成普通批阅的前置步骤。

## 登录与机器权限

现有 Daily 桥接固定 `writeascend` 客户端及机器凭据，不能把它直接交给互批项目。下一步新增独立客户端（设计名 `writing-peer`）、独立回调与机器令牌，使用授权码、PKCE、一次兑换和来源账号持续核验。原客户端行为和默认关闭策略保持。

互批机器只允许兑换/核验/退出自己的登录授权；禁止调用现有目录写入、模型工作授权和报告摘要签发接口，也不能核验或撤销另一个客户端的 grant。源账号注销/停用仍应使所有相关客户端失效。教师按当前获授班级管理互批；学生按自己的轮次分配访问，不能通过知道别人的稿件 ID 获取文章。

跨项目来源接口使用另一个限定为互评快照的机器凭据，不复用 Daily 根机器令牌。浏览器不持有机器凭据；来源地址与回调由服务器登记，不能在请求中指定任意站点。

## 材料和标准快照

老师从当前有权限的任务选择指定稿次，核对脱敏的题目、原文转写及标准。材料可以来自已核对的原文识别，也可由老师手工转写；不能拿 AI 升级稿冒充学生真实原稿。只有经老师确认的脱敏文本进入互批服务；不能只去掉页面上的姓名标签，却仍把带姓名的图片或全文身份信息交给学生。

来源快照包含原任务/成员/稿次、输入摘要、rubric 版本及导出编号等服务端关联信息，以及老师确认的脱敏题目、文字与分项标准。原账号 provider/subject 仅用于服务端关联和分配，学生响应使用本轮独立代号；代号不能按真实姓名排序生成或跨轮复用。

互批映射保留原分值、总分、字数政策与时态；A2/B1 类别提供提示来源，自定义维度须老师确认描述。文字互评无法观察的书写/卷面留给老师。新映射或来源改变时形成新版本，不能修改已经开始评阅的冻结版本。

## 交付、撤销与读取

导出须有操作编号、固定内容摘要、服务目标和回执。网络重试复用同一导出，内容不同拒绝；两边不能因回执丢失建立重复轮次。导出编号只用于服务端交换，不做任何匿名公开内容链接。

互批服务在内容读取和写入前核对当前账号、轮次分配、材料/标准版本及来源有效性。来源任务停用、成员失效、原稿输入改变、老师撤销分享或权限变化，应停止相应学生访问；来源暂不可核验时停止提供内容并显示重试。不能因为缓存中还有旧文稿就继续公开。已发给浏览器的内容无法召回，不作相反承诺。

互批不以先完成 AI 批阅或发布 AI 报告为前提。老师可分享已收取且手工核对转写的首稿；学生不必先看到 AI 改写示例。当前自主二稿接口只接受已发布教师反馈作为依据，后续必须新增经核验的“同伴反馈发布版本”依据类型，保留老师反馈路径，并允许作者从已分享的本人原稿及获准发布的同伴建议进入下一稿。该扩展尚未实现，不能以现有接口已经能连接任意互批轮次作结论。

互批反馈默认先进入老师可处理的状态；作者只看到老师允许发布的反馈。恶意/泄露身份反馈可隐藏并留记录、申诉与重新分配，不直接删除证据。老师始终保留最终成绩与发布权，不由同伴档位自动换算或平均覆盖。

## 分配、回应与二稿

核心分配器已能按本轮人数/份数/排除关系形成完整平衡分配。示例训练、每轮种子保存、缺交、晚交、停用和重新分配需要在服务端事务及页面实现，不能靠重新随机生成整轮替换已经提交的评阅。

反馈要求具体位置、解释与建议；作者可以采纳、部分采纳、保留或请求帮助。回应记录使用反馈版本和评论编号，改写计划是作者自己的表达。后续连接现有自主二稿工作区时，应引用反馈/回应版本，不替学生写作文，也不改动教师原稿、历史报告或已发布成绩。

## 当前验收边界

已实现领域规则与独立包检查；没有实现本节所述授权客户端、来源交换、持久化、学生/老师页面及公网部署。下一步依次实现登录与受限来源快照，再落互评轮次和页面。正式学校目录、真实手机、真实模型、Cloudflare 发布与回滚仍按整个升级目标验收，不能因领域测试通过就宣布独立项目完成。
