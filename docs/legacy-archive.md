# 旧版批改档案

学校教师登录后，从“设置 → 数据管理 → 旧版批改档案”进入。主工作台继续使用原作文一键批改流程。此入口迁移旧JSON、保留原批语和分数，不重新调用模型。它与当前写作任务、学校学生报告和独立互批项目分开。

选择旧文件后先在本机排除已知密钥及认证字段，显示报告、班级名称、姓名条目与缺失评分标准的数量，确认后才上传。云端保存经过清理的完整业务备份，包含原设置、学生档案及文件内已有的导出/批次/评分标准/分析历史；不能恢复原文件没有保存的内容。下载完整备份不会补入个人云端模型密钥。当前上限为8MiB、10000份报告，以先达到者为准；本机工作区还原仍为32MiB。

云端按当前教师私有存储，首段和续传每次处理10份；列表每页25项。保存服务器进度后可以暂停、关闭，再从“备份文件”继续。相同业务内容重复上传、改文件名或更换被排除的密钥不增加副本。两个设备同时续传使用短期处理租约；冲突时刷新进度后继续。数据库0016仅增加索引和状态表，保留旧导入表六列及旧版本读写兼容。

历史报告可按姓名、班级或题目搜索，查看六个主要报告区，下载JSON/CSV或打印PDF。缺少原评分标准时保留实际记录的分数（含0分），明确显示“满分未记录”，不能用当前评分标准替代。具备原评分标准的报告可以载入工作台的独立副本继续编辑；这会切换当前工作区，需先保存当前批次。原档案不被覆盖。

原姓名和本机学号仍是历史信息，不能作为真实学校账号绑定的依据。本入口不自动发布给学生。已存原图外部链接不会自动加载；不承诺恢复失效照片。当前学校作业的教师发布、学生自主查看仍使用已有的任务和学生身份关联流程。

撤回使用版本校验，仅隐藏本批次未修改且没有其他有效备份引用的报告。原文件、教师修改、其他备份的引用会保留；回收站可以恢复，重复上传不会偷偷恢复已撤回文件。尚未建立成员索引的早期云端批次可以下载原文件，需重新选择完整备份建立索引后才允许撤回，避免错误地声称已隐藏报告。

打印采用单独预览文档和分页表尾，为AI来源说明预留空间。保留原纸张间距设置，较长报告可以多页，不通过截断内容压缩为一页。自动PDF检查不替代实体打印机与手机系统打印验收。

## 接口与隔离

`/api/legacy-imports`提供备份创建/列表；`/:id/continue`续传，`/:id/source`下载完整备份，`/:id/reports`按原顺序分页，`DELETE /:id`撤回，`POST /:id/restore`恢复。`/api/reports`搜索分页，`/:id`查看及版本校验后的编辑。所有接口要求教师/管理员会话及匹配当前身份的`X-Workspace-Id`，学生不能读取教师档案。下载通过已认证接口返回，不生成公开存储地址。

发布和验证见[本轮记录](verification/legacy-archive.md)。真实账号、真实旧浏览器数据、学校学生绑定、实体手机和打印机仍待试点；用户已选择稍后再验证真实账号。
