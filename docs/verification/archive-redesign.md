# 批改档案重构

本轮沿用原有批阅、报告编辑、学生归属、保存、打印/PDF、CSV、JSON 和历史迁入逻辑，重做档案信息结构与阅读界面。

## 入口与操作

- 本批报告：搜索姓名、拼音首字母、班级和编号，按班级、状态、时间筛选与排序。缺失分数显示横线，真实零分保留；未记录日期不虚构为今天。
- 班级任务：独立任务卡片，按题目、班级、学期检索，直达已有任务的核对与发布步骤，仍受原权限和阶段条件限制。分页筛选明确针对已载入任务，不声称搜索了全部历史。
- 云端批次：完整页面展示已保存批次、历史版本与可恢复的回收站，继续使用原云端存档接口。
- 历史导入：完整页面展示原系统迁入档案，保留预检、迁入、查看、独立副本编辑及原版导出功能。

列表打开报告只改变当前选择，重复点击不再隐式触发原有重新批阅请求。重新 AI 批阅放在明确菜单入口，保留原确认与计费说明。快捷批阅报告默认阅读，主动进入编辑后沿用原字段保存及成绩校准；学生关联的任务报告仍须在原任务保存教师版本和发布。

阅读页提供批改报告、作文原稿、题目与标准三种视图，保留六区内容。电脑上可用窄学生索引切换，手机上改为单列、返回列表与上一份/下一份，阅读时收起档案来源说明。移除原三栏固定高度和重复缩略报告；整体预览分批显示，实际打印仍使用原独立打印容器和 PDF 设置。

本批导出明确标为“全部已完成”，不会让用户误以为筛选条件同时改变 CSV/PDF 的导出范围。载入其他云端批次须先确认当前工作区切换；取消后页面和原报告保留。

## 验证范围

新增三组数据行为测试：缺失分数与零分、日期排序与时间范围、同名学生身份和拼音首字母检索。根工程 254 项通过，构建与正式 Worker dry-run 通过。浏览器使用本机合成账号与既有合成报告，未调用付费模型，未发布给真实学生。
