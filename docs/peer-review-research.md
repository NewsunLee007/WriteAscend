# 独立互批项目：研究依据与后续核对

2026-10-17 初步来源审查。独立互批应用尚未实现；本文件记录已经核对的依据与未完成的证据，不能把自主二稿模块称为互批。

## 已核对的依据

Double、McGrane 与 Hopfenbeck 的元分析纳入 54 项跨学段、跨学科研究，整体效应量为 g=0.31，支持将同伴评价作为形成性学习活动。它不是中国初中英语作文专用量表的验证，也不能据此承诺每个学生提高固定分数。文中关于匿名性的结果并不一致，不能把匿名当作必然提升成绩的机制。[期刊原文](https://link.springer.com/article/10.1007/s10648-019-09510-3)

Cambridge B1 学校写作框架区分内容、交际达成、组织和语言，适合作为待映射的维度来源。官方指南和手册已定位，当前网页检索可读取框架说明，但 PDF 全文读取超时；分档、任务类型及低水平适配仍须核对后再定稿。[B1 教师指南](https://www.cambridgeenglish.org/images/231794-cambridge-english-assessing-writing-performance-at-level-b1.pdf)、[学校手册](https://www.cambridgeenglish.org/de/Images/168143-cambridge-english-preliminary-for-schools-teachers-handbook.pdf)

CEFR 2020 官方全文已取得，目录确认包含书面产出、监控与修正、语法准确性、连贯衔接和附录四写作评价表。下一步需精读 A2/B1 描述及验证章节；能力等级不能自动等同于中国某个年级，也不能把本项目改编表描述为已获得量表认证。[CEFR 官方原文](https://rm.coe.int/common-european-framework-of-reference-for-languages-learning-teaching/16809ea0d4)

## 必须继续核对

- [教育部 2022 课程标准发布页](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)：官方检索记录已确认英语标准入口，但正文访问超时，需取得正确英语附件再逐项对应初中表达与修订要求。不能误用检索中出现的旧版英语或日语 PDF。
- [A2 Key for Schools 教师指南](https://www.cambridgeenglish.org/Images/600973-teacher-guide-for-writing-a2-key-for-schools.pdf)：官方文件已定位，当前全文读取超时；不能直接假设 A2 与 B1 使用完全相同的分维度方式。
- [同伴评价设计要素系统综述](https://link.springer.com/article/10.1007/s10648-023-09723-7)：原文可读取，下一步核对训练、反馈形式、分配、匿名和作者回应的证据边界，再形成实施规格。

## 目前确定的产品约束（本项目设计判断）

1. 教师为当篇发布的 rubric 版本始终是评分依据。研究框架用于学生可理解的描述及评阅提示，不在背后增加另一套分数；自定义维度必须由教师确认映射和描述。
2. 学生先完成示例评阅与反馈练习，再评真实作文；反馈需引用具体位置、说明原因并提出可操作建议，作者可以说明采纳、部分采纳或保留的理由。
3. 先评内容与表达是否清楚，再看衔接和本人能判断的语言问题；允许“不确定，请老师核对”，避免把初中学生训练成只数语法错误的评分员。
4. 学生评价只作为学习反馈，教师保留最终评分与发布权。评价质量、作者回应和真实二稿分别记录，不能用提交次数或两次 AI 分数差替代学习效果。
5. 另建应用、部署与授权客户端；经接口分享指定任务/标准/稿次的最小内容。去除姓名、账号、班级和照片身份区后再分配；不能直接把当前带身份的报告或整页照片作为“匿名互评”材料。
6. 禁止自评，限制分配数量，提供缺交、恶意反馈、申诉、重新分配和教师查看渠道。默认两份互评等具体参数属于待试点设计，不能借元分析宣称其为已验证最优值。

落地前需要完成上面的标准核对、适龄描述、教师映射界面及小班试点验收。现有身份、评价标准、原稿/报告和自主修订版本可供接口引用，但不开放给未分配的同学。
