## 课堂描述与本篇教师标准的对应（项目设计）

以上官方框架为选维度和难度提供依据；本项目中文提示与“达到、部分达到、待改进、不确定”是原创课堂支持设计，不是已经在本校验证的新量表。它们不换算成考试 0–5 档、教师原分数或 CEFR 证书等级。

| 教师当篇标准 | 学生观察提示 | 处理原则 |
| --- | --- | --- |
| 内容/要点 | 找到已经说清的要求，指出仍需补充的具体信息 | 题目原要求优先，不能为了互评自行添加要点 |
| 结构/衔接 | 说明哪段读得顺、哪里需要重排或补充联系 | 基础组接受简单自然的连接；发展组关注更清楚的段落关系 |
| 语言/词汇/语法 | 先判断意思能否读懂，再指出自己能判断的具体词句 | 不要求穷尽语法问题；不确定时提问，由老师核对 |
| 交际/语气/格式 | 思考写给谁、要完成什么沟通 | 由老师按本篇任务确认是否启用，不能默认与 A2 的独立分维度相同 |
| 字数 | 按本篇字数和严格/宽松设置核对 | 保留教师政策，不能照搬 Cambridge 某类考试的字数 |
| 书写/卷面 | 文字互评无法观察 | 保留老师原有分值，学生不打该项档位，也不将其记成零分 |
| 自定义项目 | 由老师填写学生提示及分档描述 | 未映射或未确认时不能开始，不通过关键词建议自动发布 |

教师确认的原维度、名称、分值、总分、字数政策、时态和任务/rubric 版本保留。映射只是学生使用的说明；同伴反馈明确标记形成性用途、最终评分由教师负责。关键词映射只是未确认建议，不能代替老师的判断。

## 学习活动的实现约束

1. 学生先做示例评阅练习，再接触真实材料；正式文章须老师核对并脱敏。姓名、班级、账号和纸面身份区不能通过原图或文字继续泄露。
2. 至少一处优点有精确原文引用，同时提出一条可操作建议；指出某项待改进须给同项建议，不确定须提出具体问题。不能要求学生为缺失的信息伪造一句原文，因此整体反馈也可说明遗漏。
3. 作者逐条说明采纳、部分采纳、保留或提问的理由；采纳时说明自己准备怎样改，再关联真实二稿。作者不被迫接受每条同伴意见。
4. 分配禁止自评和重复稿件，老师明确选定份数，受限条件无法平衡时整体提示，不悄悄少分几份。每人两份等默认值只是试点选择，不声称经过研究证明最优。
5. 教师可训练、抽查、隐藏不当反馈、处理申诉和重新分配；互评分档不能自动覆盖教师总分，也不以两次 AI 分数差证明能力增长。
