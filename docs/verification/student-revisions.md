# 学生自主二稿验证

2026-10-17。实际本地 Wrangler/D1/R2/Queues、合成学校身份与照片、模拟模型响应，没有真实学生或真实 AI 费用。迁移 0013 仅应用隔离本地数据库，正式域名及远程数据库尚未变更。

## 已验证

- `npm test`：135 项通过，完整 [测试输出](student-revisions-tests.tap)。新增 8 项学生修订协议与实际 SQL 测试；原 Worker 身份测试补充工作区/跨源拒绝。覆盖真实下一稿输入和原批阅管线、同名与跨账号隔离、来源/班级撤权、幂等/多设备 CAS、逐次历史、退回/撤回/重提、反馈更新后明确更新依据、撤回后保留学生自己的新稿、照片所有权/次数、不得覆盖已有下一稿、结果与首稿保留。
- 异步准备期间撤回父反馈，提交事务不会写入旧依据；收取准备期间替换父稿输入，不建立部分下一稿。丢失创建回执后即使反馈撤回，也可取回本人已建立的修订区，不能借此读取已撤回反馈。
- 教师对已接收的二稿重拍页面时，保留学生修订来源与反思，旧输入历史继续存在。
- `npm run build` 和 `npm run worker:check` 通过，后者是 dry-run。构建保留既有大包与 lucide 指令提示，没有远程部署。
- [完整浏览器流程](student-revisions-browser.json)：学生从自己的反馈开始，使用本篇标准说明修改，离线选图写入 IndexedDB，恢复网络刷新后仍保留原图与文字；另一设备先保存时不自动覆盖，学生明确采用本机内容后才继续保存。验证两页排序、保存、提交、教师退回、学生重提、教师核对收取及原班级一键批阅。
- 老师收取后自动定位第 2 稿，再明确点击原一键批阅。学生与教师的首次/第二稿共 2 次合成模型调用；保存、上传、退回、收取、缓存恢复和跨设备冲突不产生额外模型调用。第二稿须另行由教师发布，首稿反馈仍保持原版本。
- 第二稿报告保留学生自主修订来源，学生已发布报告中可查看自己的修改记录。另一个同名学生、另一位老师不能读取修订或照片。
- 退出前提示本机未保存内容，退出后本机缓存为空；单独验证缓存代次阻止退出前延迟写入重新生成缓存，并保留其他账号的数据。
- 375/390/768/1440px 学生修订页没有整体横向溢出。390px 学生页和 1440px 教师核对页截图已目视检查；顶部按钮已缩短标签并复测，避免手机折行。截图为合成数据，真实软键盘和相机仍待实测。
- [8 组当前回归](student-revision-regressions.json)：自主二稿、报告历史/学生发布/Daily 同步、先选学生拍照、独立 OCR、原完整教师流程与导出、批量重试、个人模型密钥，以及原扫码收作业均通过。每项包含当前脚本摘要和运行时间。

## 当前限制

正文是手写照片，尚无在线作文正文编辑器。弱网本机缓存不能替代原稿；无 IndexedDB、存储容量不足或网站数据被清除时需要重新选择原图。HEIC、真实 iPhone/Android、软键盘、正式公网、真实手写识别和评分质量尚待验收。老师收取准备失败可能留下未引用的私有照片副本，资源维护不能删除仍被输入、报告或历史引用的原图。

本轮没有修改实际 Daily 集成源码、正式配置、正式学校目录或运行中的正式进程；未把既有 Daily 测试记录算作新运行。互批项目、真实环境联调、可回滚部署与最终功能逐项验收仍未完成。操作和权限设计详见 [学生修订说明](../student-revisions.md)。
