# Daily 班级与个人批阅标准

快捷批阅现在是班级任务的准备入口：**学生与题目 → 批阅标准 → 核对开始 → 收取作文 → AI批阅 → 核对与发布**。工作台与写作任务的新建按钮都进入这套准备流程。题目、标准及学生确认之前，不出现作文上传或批阅按钮。已有私人批次可继续处理，临时作文也保留独立的私人批阅入口。

## 自动关联班级

学校模式从 `/api/classes` 获取 Daily 本次会话的授权班级，只选用同时具备 `roster.read`、`writing.manage`、`writing.grade` 的班级。优先带出上次仍获授权的选择，否则选第一个可用班级；旧版本机701班不会充当学校班级。年级来自所选班级，只读展示。同一年级、同一学期的多个班级可以共用任务，一次最多20班。

标准核对后保存任务草稿，再通过现有任务接口读取完整分页名册。教师核对人数、学生及标准后明确确认，后端重新核验名册摘要与任务版本，才建立学生快照并进入现有收取流程。收取、姓名首字母检索、批阅、发布继续使用稳定的学校账号关联。没有授权班级时给出说明，不自动降级到本机名单。写作单仍可从任务的“打印写作单”步骤生成。

## 标准选择与二次编辑

六类内置课堂标准：叙事经历、人物与地点介绍、观点表达、书信邮件与通知、看图与情景、建议与说明。选择只带入评分要求与语言控制，不替换本篇题目或范文。各类分别强调相应任务目的；词数、时态、满分、维度名称、分值、描述、松紧度和语言难度仍可修改，AI设计与文档导入能力保留。明确的题目词数范围与模板不一致时提供提示及“一键采用题目词数要求”，不擅自替教师修改。

评价框架参考[已核验的研究和原始量表](peer-review-research.md)中 Cambridge A2/B1 的内容、组织、语言及交际目的。中文描述、年级词数和分值权重是本项目可编辑的课堂预设，不能宣称是官方考试细则或经过本校效度验证的量表。默认不以生僻词、复杂句数量或书法美观程度加分；图像模糊应重拍，避免按图像质量扣学生分。默认20分按8/6/4/1/1分配，变更满分采用半分最大余数分配，保证合计准确。

“仅用于本次”直接继续下一步，由任务保存标准快照。“另存到我的标准”创建个人模板；“更新这份个人标准”明确更新已有模板。不同年级模板用于当前班级时沿用 Daily 年级，提示核对词数，并改为另存副本，避免覆盖原年级标准。个人库支持搜索、收藏、归档/恢复和最近50个历史版本选用。按教师账号隔离，换设备后可从云端“我的标准”选用。

本机历史记录继续保留；选用时默认只恢复标准，需要原题目、要点及范文时另选“连同原题目恢复”。旧版完整报告、导出及历史业务数据不改写。评分器只对明确命名的词数维度应用词数扣分，不再把第四个任意维度视作词数项；重新载入标准不额外添加零分词数维度。

## 后端与发布

迁移 `0017_teacher_rubric_library.sql` 添加教师模板、不可变版本、幂等操作回执三张表。`GET/POST /api/rubric-templates` 和 `GET/PUT /api/rubric-templates/:id` 需要教师或管理员会话；历史版本通过 `GET /:id/versions` 读取。写入同时校验同源、工作区、归属和预期版本。每次操作的回执、模板更新及版本记录在同一事务提交；重试使用稳定模板编号，不重复创建。旧页面或另一设备修改后发生版本冲突，拒绝覆盖并要求刷新。

每位教师最多200份模板、每小时最多120次修改。模板只保存评分字段和语言难度，不存学生名单、作文题目或模型凭据。已建立任务保存独立文档，后续编辑、归档或恢复模板均不改动已有任务、报告、发布或互评引用的版本。

迁移只新增表和索引，旧 Worker 可与迁移后的数据库兼容。部署前导出独立测试库并记录恢复书签；必要时回退明确的旧 Worker 版本，保留新增表及教师保存的标准。数据库恢复与 Worker 回退分别处理。正式域名不在本次切换范围。
