# 独立互批轮次与课堂流程

2026-10-17。独立项目 `apps/peer-review` 已在本机接通实际 Worker、独立 D1、Daily 合成账号和 WriteAscend 材料来源。教师一键批阅仍使用原流程；互批不要求先生成或发布 AI 报告。尚未部署公网版本。

## 教师与学生的操作

教师从已确认导入的材料进入“设置本轮学生提示与分配”，逐项核对原标准对应的学生提示，选择基础表达或进一步展开的支持方式，并确认每人评阅份数。原分项、分值、总分、字数、严格字数设置和时态保留。自定义维度必须补充提示与档位描述；手写卷面只给老师核对。

每轮 2–300 人，每人 1–5 份且少于人数。分配禁止自评、重复和老师排除的关系，每人给出与收到的份数相同；无法满足时整体停止建立。轮次冻结材料、标准、参与身份和分配，不在刷新时重新抽签。匿名代号按每轮私有随机顺序建立，不能从导入材料编号推断学生；仅教师看到姓名及学校账号短编号。

学生沿用学校账号，在本轮完成三个示例练习后提交反馈。学生逐项选择“达到、部分达到、待改进、请老师核对”，通过句子选择器引用原文，并写具体优点、理由和修改办法。负面判断必须有同维度的建议，不确定必须提出具体疑问；同伴档位不换算或覆盖教师成绩。

评阅草稿在停止编辑 5 秒后保存到独立服务，也可手动保存；不会自动提交。活动中的页面续期学校登录，暂时核验失败时隐藏受保护内容，并保留当前页面尚未保存的输入供恢复。明确退出或失效登录清除页面身份。此阶段没有实现全部互批表单的离线持久缓存，不承诺关闭浏览器后恢复未保存输入。

提交后由原任课教师核对，明确发布给作者，也可隐藏或退回补充。作者只能查看自己的已发布建议，逐条说明采纳、部分采纳、保留或提问的理由，采纳时写出怎样修改。反馈改版后原回应不会自动套用到新版。回应保存为版本；离开未保存页面会提示，保存一份回应不会清空其他份的未保存输入。

## 持续来源与成员核验

独立材料导入权限不能直接作为学生读取权限。Daily 新增 `writing-peer-rounds.mjs`，只给固定互批机器客户端提供 `round/preview`、`round/authorize`、`round/check`。轮次绑定原任课教师、导入摘要、班级及授权版本和冻结成员；学校账号原始 Cookie、口令及 PIN 不传到互批 Worker。

普通教师建立的轮次按教师账号仍有效、当前班级授权与实际有效学生名册持续核验，不因教师的短时交互登录自然到期或退出互批而中断全班。教师账号状态通过 WordUp 只读查询 `teacher_accounts.id,status`；学生通过只读名册适配器核验。管理员建立的轮次另存 Daily 内部加密来源证明，受原会话期限和注销代次限制；需要时由管理员重新登录核对同一冻结绑定。

学生访问必须属于冻结参与名单且当前仍有效；移出名单、停班、撤销教师授权、停用来源教师、来源原稿替换、分享撤回或上游暂不可达均停止正文读取。学生核验回执不返回其他人的姓名或身份对应。请求收到完整正文后再核验写入权限，数据库同时检查当前会话、轮次状态和版本，防止旧页面或另一设备覆盖新版本。

WriteAscend 机器接口增加 `status`，只返回已确认导入的固定分享是否有效及摘要，不返回作文，也不需要伪装教师交互登录。来源任务正常关闭时暂停访问；重新开放且标准、原稿和成员未变时恢复。明确撤回分享仍永久停止该分享，需重新准备材料。

## 存储、接口与部署边界

独立迁移 `0003_peer_rounds.sql` 保存轮次、私有身份对应、分配、训练、不可变反馈版、教师处理记录、作者回应版和操作去重记录；仅用于本机 QA。写入要求同源、当前工作区、有效账号与版本。核心接口为 `/api/rounds`、`/api/rounds/:id`、`/api/assignments/:id`，以及各自的训练、评阅、发布和回应子路径。学生不能读取教师导入接口、同班其他人的作者反馈或未分配的评阅。

任务列表每页核验最多 4 个候选，继续加载可访问完整历史；同时核验最多 2 个轮次。请求正文上限 2 MiB，轮次标准存储前另查字节数。来源交换可配置 `SOURCE_SERVICE` 服务绑定，或使用固定 `SOURCE_ORIGIN`，始终只转发独立交换凭据。此设计考虑 [Cloudflare D1 限制](https://developers.cloudflare.com/d1/platform/limits/) 与 [Workers 请求和服务绑定限制](https://developers.cloudflare.com/workers/platform/limits/)，不把本机运行结果当作远程配额或部署验收。

Daily 集成包现在包含 22 个文件；SHA 预检与原版、旧桥接、18 文件版、21 文件版升级/回滚验证已完成。实际本机 Daily 源码已安装，快照为 `audit/private/daily-bridge-2026-10-16T22-22-02-553Z`；正式环境变量和进程未变，正式目录没有写入。
