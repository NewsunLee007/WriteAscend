# 模型设置与页面细节验收

日期：2026-10-17。本阶段保留教师一键大模型批阅、已有报告字段、评分设置、导出及独立互批项目，仅改进模型连接和页面使用细节。

## 已处理

- 设置页明确区分作文批阅与图片文字识别；连接向导按用途、服务商、型号、API Key 排列，带官方帮助及计费入口。
- 国内外精选目录、账户自动刷新、用途过滤、专用 OCR 接口和同供应商密钥复用，具体范围见 [模型配置说明](../model-catalog-and-ocr.md)。没有真实供应商密钥时不宣称模型调用或教学准确率已验收。
- 手机控件字号和点击区域、长标题与型号换行、设置卡片、分析按钮排列、任务步骤栏、打印单及收取页面颜色、底部安全区域与快捷批阅固定栏位置已核对。修正旧样式覆盖导致固定批阅栏被导航遮挡的问题。
- 班级列表支持搜索班级、年级、学期，并按自然数字排序。
- 未保存模型配置有离开确认及浏览器关闭提醒。配置保存后自动应用至相应用途，移除模型不删除既有报告。
- 页面模块缺失或更新后旧标签页无法加载模块时，显示恢复入口；任务模块异常保留工作区导航。通过暂时移走本机一个构建模块进行故障注入，实际看见恢复提示；还原模块并重新加载后正常进入写作单。

## 验证

根工程 222 项测试、独立互批 9 项测试通过。根工程构建、两个 Worker 类型检查与 staging dry-run 通过。新增测试覆盖目录过滤、缓存隔离、千问分页、凭据隔离与复用、专用 OCR 请求限制和结果标准化、个人及学校 OCR 队列调用。测试使用合成凭据与模拟接口，不产生真实模型调用费用。

浏览器使用本机合成学校与教师，核对 375px 手机、390px 模型向导、768px 平板、1440px 桌面。主要页面包含工作台、任务、快捷批阅、档案、学情、班级与学生、模型设置；另查看手机写作单、收取、AI 批阅、核对发布和完整报告。已测量的页面宽度没有超出文档视口；任务步骤栏保留内部横向滑动。

本机账户目录返回 7 条模拟型号，筛选出批阅 2 条、OCR 4 条，排除绘图、语音和未知文字型号；验证添加专用 OCR 后用于识别，再复用同域名密钥保存视觉批阅模型。保存后各用途选择正确，未调用真实服务商。

截图与量测保存在被 Git 忽略的 `output/model-layout-checks.json`、`output/model-setup-desktop.jpg`、`output/model-setup-mobile.jpg` 及 `output/layout-*.jpg`，均为合成数据。真实手机相机、真实中文姓名/英文手写识别、各服务商实际账户权限和课堂评分效果仍需后续小批验收。
