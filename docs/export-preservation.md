# 批改报告保留与补齐清单

新版以现有 WriteAscend 报告为默认输出。保留所有主要栏目、教师编辑能力和导出设置。附件只用于补齐解释与修订信息，不替换既有版式，不把所有报告简化为 Word 示例中的五部分。

## 必须保留的报告内容

| 当前内容 | 当前数据 | 新版处理 |
| --- | --- | --- |
| 学生、班级、序号与任务信息 | `student_name`、`class_name`、`student_no`；assignment | 保留显示；另存统一身份与打印时快照 |
| 总分和各维度分数 | `total_score`、`breakdown`；`rubric.items` | 保留教师设置和修改结果，不用固定四维替代 |
| 词数与词数要求 | `word_count`、`original_essay`、`rubric.wordCount` | 保留；增加计数规则版本，历史计数不自动重算 |
| 总体评价 | `brief_comment` | 保留中文点评和教师编辑 |
| 优秀表达及点评 | `highlights[].text/comment`，兼容旧 `excerpt/why_good` | 保留最多三条的默认展示；区分真实摘录与鼓励语 |
| 诊断与提升 | `errors[].orig/corr/type/note` | 保留原句、改句和中文原因；增加原文定位与不确定标记 |
| 内容优化建议 | `content_logic` | 保留内容拓展、句式升级、结尾优化三部分 |
| 升级版习作 | `optimized_essay` | 保留基于学生原稿的润色和年级难度设置 |
| 标准参考范文 | `standard_reference`、`assignment.modelEssay` | 保留，与学生升级稿继续区分 |
| 题目与作文原稿 | `pdfConfig.showPrompt/showOriginal`、`original_image_url`、`original_essay` | 保留原有开关；图片改为私有文件引用 |
| 班级综合分析 | 当前及历史分析结果 | 保留历史、再次分析与打印；仅在本班范围统计 |

默认评分结构仍为可编辑的 20 分：内容完整度 8、语言准确性 6、篇章结构 4、词数要求 1、书写规范 1。严格程度、字数严格模式、年级、时态、范文难度、英文难度控制及半分编辑能力都应保留。15 分等任务继续由教师自行设置。

## 必须保留的编辑与导出能力

保留教师在纸张视图中修改身份、总分、分项、评语、亮点和纠错的操作；保留单份与批量打印、浏览器打印为 PDF、CSV、JSON 快照、结果恢复及学生历史档案。CSV 原七列保持兼容：序号、班级名称、学生姓名、实际得分、题目满分值、写作任务名称、批改时间；统一 ID 等新增字段可作为另一个导出选项。

保留 A4、页边距、行距、字号比例、章节和段落间距、题目与原稿显示设置。手机版采用阅读卡片，打印时仍由同一份报告数据生成现有纸面结构。

当前 `.docx` 主要用于导入评分标准，报告直接导出路径为打印/PDF、CSV、JSON；未发现独立生成 Word 报告的实现。可编辑 Word 导出作为后续可选增强，不作为已经存在的功能承诺。

## 从附件补齐的内容

附件的逐句批改把“原文内容、修改建议、对应润色”放在一起，可以在现有纠错中提供可切换的三列教师视图；手机按原句、建议、修改后纵向展示，不强制横向滚动。

增加修改前后差异显示。基础纠错与表达升级分别标记，原来正确但有其他写法的句子不计为语法错误。润色差异以数据比较产生，不依赖模型自己插入方括号维持一致。

增加可选的分项评分说明、扣分或封顶原因、两项优先修订目标、作者回应与二稿对照。评分说明是现有分数的证据，不另生成一套独立总分；若旧报告没有说明，则显示未提供，不能伪造历史依据。

为每条反馈标记来源：AI 建议、教师确认、同伴建议。原稿正文、AI 润色稿与学生自主二稿必须分别保存。不能把 AI 生成的升级句当作学生已经掌握的表达。

## 数据兼容与发布规则

采用 `legacy-report-v1` 兼容投影：保留上述字段与未知业务字段的经过凭据过滤的旧数据，建立稳定的 `criterion_id` 与旧中文维度标签映射。历史 `breakdown` 不因教师修改维度名称而失去归属。标准规范化、总分联动、字数规则、难度控制与修复过程都记录版本。

导入历史报告只做结构适配，不调用 AI、不重新校准分数、不重写教师评语。历史报告缺失 rubric、任务信息或图像时明确标记；不能用当前任务的标准静默填补。

新增 `report_revision` 和教师修改记录。后台重试 AI、难度修复或生成新稿时，只生成新版本；教师已确认的版本保持可追溯。严格限制自动修复可以修改的字段，保护原稿、身份和人工分数。

教学模式可在互评及二稿前暂缓向学生展示完整升级稿与标准范文；教师端保留原有查看、编辑和导出能力。完整报告与“只给学生修订提示”的发布配置分别保存，不能删除已有内容实现隐藏。

## 报告回归验收

先建立不含真实姓名与作文的合成样例，再拆分原代码。至少包括：普通报告、长作文跨页、空白与识别不清、多维评分、半分与教师改分、超短作文、不同严格程度、旧字段别名、重复原句、缺图、中文长评语及原文含划掉内容。

验收检查：主要栏目内容齐全；旧字段与人工修改保留；维度映射与总分一致；缺失数据不补造；打印无截断、重叠和遗失；CSV 前七列兼容；手机不需横向滚动。评分算法如果需要修正，单独记录变更及样例对比，不借代码拆分顺带改变历史成绩。

本阶段只完成内容与字段对照，未修改原 HTML 或附件，也未宣称新版打印已经通过视觉验收。
