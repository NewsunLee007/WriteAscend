## 教师操作

写作任务 → 打开任务 → 任务设置 → 本篇评价标准 → **修订本次标准**。直接编辑当前词数、分值、维度和要求；冲突时可点击“采用题目词数要求”。内置/个人标准及保存复用折叠为可选项。填写修订原因并核对影响后，保存新版本，自动进入AI批阅。题目与标准词数冲突时禁止创建新模型批阅，并提供直接修订入口。保存标准不调用模型、不发布学生反馈；重新批阅仍按供应商规则计费。

题目、任务学生和已收原图保持对应，当前稿次改用新标准版本；旧标准、输入清单、照片版本和报告完整保留。旧报告成为历史结果，列表明确显示“待重新批阅”，已完成筛选不再将其混入；不能直接按新标准发布。原写作单二维码作废，继续扫码前须重新打印；待上传的旧纸张可先选学生、核对后上传。

已有任何发布记录（含撤回）或互评交接记录（含撤销）的任务不允许改动本轮依据，须另建任务。后台仍在批阅时也不能修订。需要任务所有班级的名册、任务管理和批阅授权，保存前再次向Daily核验。
